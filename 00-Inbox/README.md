# 📥 收件箱使用指南

## 用途

所有碎片素材、临时想法、待处理的信息统一丢到这里。

> **原则**：先收进来再说，不要当场整理。

## 工作流

```
收件箱 ──→ Wiki ──→ 行动卡 ──→ 排期
  ①        ②         ③         ④
```

### ① 收件箱 → 清理
- 定期（建议每周）回顾收件箱
- 有价值的素材 → 整理成 [[10-Wiki]] 条目（告诉我"整理收件箱"）
- 临时任务 → 直接生成 [[20-Actions]] 行动卡
- 过期无用 → 删除或归档

### 收件规范
- 一条笔记一个主题
- 保留来源链接
- 可以用模板 `闪念笔记` 快速记录
