# 📊 项目看板

> 自动汇总 60-Projects 下所有项目状态。每个项目需在 YAML 中标注 `status`。

## 按状态汇总

```dataview
TABLE 
  status AS "状态",
  date(now).year - date(start).year AS "持续时间(年)",
  date(today) - date(start) AS "运行天数",
  file.mtime AS "最后更新"
FROM "60-Projects"
WHERE file.name != "📊 项目看板"
  AND file.name != "README"
SORT 
  choice(status = "进行中", 1,
  choice(status = "卡住", 2,
  choice(status = "待办", 3, 4)))
```

## 进行中

```dataview
LIST file.link
FROM "60-Projects"
WHERE status = "进行中"
SORT file.mtime DESC
```

## 卡住 / 待办

```dataview
LIST file.link + " — " + choice(status = "卡住", "⚠️", "📌")
FROM "60-Projects"
WHERE status = "卡住" OR status = "待办"
SORT file.mtime ASC
```

## 如何使用

1. 在 `60-Projects/` 下新建项目笔记
2. 在 YAML 顶头加上 `status: 进行中 | 卡住 | 待办 | 已完成`
3. 可选：`start: 2026-07-16`，`deadline: 2026-08-01`
4. 看板自动更新，无需手动维护
