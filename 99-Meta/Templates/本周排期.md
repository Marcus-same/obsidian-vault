# 📅 本周排期

## 本周待办总览

```dataview
TABLE deadline as 日期, priority as 优先级, status as 状态
FROM "20-Actions"
WHERE !completed
  AND deadline >= date(today) - dur(1 day)
  AND deadline <= date(today) + dur(7 days)
SORT deadline ASC, priority DESC
```

## ⏰ 逾期待办

```dataview
TABLE deadline as 截止日期, priority as 优先级
FROM "20-Actions"
WHERE !completed AND deadline < date(today)
SORT deadline ASC
```
