# 🏠 孟的 Obsidian 知识库

## 快速入口

| 操作 | 位置 |
|------|------|
| 📥 **丢素材** | `00-Inbox/` — 看到什么先丢进去 |
| 📝 **写日记** | `01-Daily/` — 每日自动生成 |
| 🧠 **整理知识** | `10-Wiki/` — 收件箱加工后的产物 |
| ⏳ **行动卡** | `20-Actions/` — 可执行的任务 |
| 📅 **周回顾** | `30-Weekly/` — 每周复盘 |

## 目录结构

```
📥 00-Inbox/          ← 收件箱：碎片素材、临时想法
📝 01-Daily/          ← 日记（自动生成）
📁 01-Projects/       ← 有截止时间的项目
🗺️ 02-Areas/          ← 持续关注的领域
      ├── HR/          ← 👈 你的主战场
      ├── 个人成长/
      └── 技术工具/
🎙️ 02-Interview/      ← 面试记录
👤 03-Candidates/     ← 候选人档案
📚 03-Resources/      ← 系统学习资源
🗄️ 04-Archive/        ← 归档
💡 05-Zettelkasten/   ← 永久笔记
🧠 10-Wiki/           ← 🆕 知识中间层
⏳ 20-Actions/        ← 🆕 行动卡
📅 30-Weekly/         ← 🆕 周回顾
⚙️ 99-Meta/           ← 模板、脚本、附件
```

## 工作流

```
收件箱 ──→ Wiki ──→ 行动卡 ──→ 日记/周回顾
  ①        ②         ③          ④
```

① 看到好文章、收到简历、有了想法 → 丢进 `00-Inbox/`
② 素材积累够了 → 整理成 `10-Wiki/` 条目（找我或手动）
③ 从 Wiki 提炼出可执行的事项 → 生成 `20-Actions/` 行动卡
④ 每天看日记顶部的 Dataview 行动卡提醒，每周做 `30-Weekly/` 复盘
