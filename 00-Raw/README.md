# 00-Raw 原始素材层

> LLM Wiki 的原始素材仓库。LLM 只读不写。

## 用途

把看到的文章、报告、PDF、网页剪藏丢到这里来，然后对我说**"摄入 [素材名]"**，LLM 会自动：

1. 读取素材内容
2. 提炼关键要点
3. 在 10-Wiki 创建/更新概念页
4. 在 10-Wiki/来源/ 写摘要
5. 更新 index.md 和 log.md

## 来源建议

- **Obsidian Web Clipper** — 浏览器插件，一键剪藏网页为 Markdown
- **手动粘贴** — 复制内容直接新建笔记
- **直接丢文件** — PDF、Word 转成 Markdown 放进来

## 与 00-Inbox 的区别

| 目录 | 放什么 |
|------|--------|
| 00-Raw | 完整的文章/报告/资料（有价值、需要消化） |
| 00-Inbox | 碎片想法、待办笔记、随手记（简短、零散） |
