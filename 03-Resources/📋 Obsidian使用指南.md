## 核心概念速览

### 双向链接（最重要的概念）
```
在笔记 A 里写 [[笔记B]] → 笔记 B 的反向链接面板自动出现笔记 A
不需要目录，链接就是导航。
```
**用法：** 想到任何相关的笔记，就打个 `[[`，选目标笔记。链接多了，知识网络自然形成。

### 图谱（Graph）
可视化你的笔记网络。点 = 笔记，线 = 链接。孤立笔记 = 没被链接的点。

**不要过度依赖图谱**，它看起来酷但日常导航用搜索和链接就够了。

### 标签 vs 链接
| | 标签 #tag | 链接 [[]] |
|------|---------|----------|
| 用途 | 类型/状态标记 | 概念关联 |
| 示例 | `#招聘` `#MOC` | `[[STAR面试法]]` |
| 场景 | "这篇笔记是什么类型" | "这篇笔记和什么有关" |

## 你的 Vault 工作流

### 每天 10 分钟

```
上午打开 Obsidian
    → Ctrl+N 创建今日笔记（自动套模板）
    → 写今日三件事

随时
    → Ctrl+Shift+Q 闪念捕获（QuickAdd 快捷键，需设置）
    → 或者 Ctrl+N → 默认存到 00-Inbox/
```

### 每周 30 分钟（建议周日下午）

1. **清空 Inbox**：`00-Inbox/` 里的笔记，能分类的分类，没用的删掉
2. **补链接**：打开图谱 → 找孤立节点 → 想想和什么有关 → 补 `[[]]`
3. **提炼知识卡片**：有价值的 Inbox 笔记 → `Ctrl+Shift+K` → 选"知识卡片"模板 → 补充"我的思考"
4. **更新 MOC**：如果有 3+ 篇笔记属于同一主题，创建或更新 MOC

### 每月 30 分钟

1. 用 Dataview 扫"重要但未复习"的笔记：
   ```
   \`\`\`dataview
   LIST
   FROM ""
   WHERE importance = "⭐⭐⭐" AND status = "草稿"
   \`\`\`
2. 归档：过期的项目笔记 → `04-Archive/`
3. 更新首页 `🏠 知识库总索引.md`

## 插件使用指南

### Dataview（数据查询）

在笔记里写代码块，自动列出符合条件的笔记：

**列出所有招聘相关笔记：**
```
\`\`\`dataview
LIST
FROM "02-Areas/HR/招聘面试"
SORT date DESC
\`\`\`
```

**列出本周新建的所有笔记：**
```
\`\`\`dataview
LIST
WHERE date >= date(today) - dur(7 days)
SORT date DESC
\`\`\`
```

### Templater（模板增强）

已配置好模板文件夹 `99-Meta/Templates`，新建笔记时：
1. `Ctrl+P` → 输入"Templater: Insert"
2. 选择模板 → 自动填入日期等动态字段

QuickAdd 配置后可以一步到位（Ctrl+Shift+Q 直接弹出选模板）。

### QuickAdd（快速捕获）

需要设置快捷键（一次性的）：
1. 设置 → QuickAdd → 新建 Macro
2. 命名为"闪念笔记" → 添加 Capture 动作 → 目标文件填 `00-Inbox/闪念笔记.md`
3. 设置 → 快捷键 → 搜 QuickAdd → 绑 `Ctrl+Shift+Q`

之后任何时候按 `Ctrl+Shift+Q`，弹出输入框，写完回车，自动追加到闪念笔记。

### Smart Connections（AI 关联）

打开任意笔记，右侧面板自动显示语义相似的笔记。离线运行，数据不出本地。

## 避坑指南

### ❌ 别做的事

1. **别追求完美分类**。分类犹豫超过 30 秒，随便放，用链接补
2. **别一下子装 50 个插件**。目前 4 个够用，有具体需求再加
3. **别把所有时间花在"搭系统"上**。记笔记比搭系统重要 100 倍
4. **别追求笔记数量**。10 篇有思考有链接的好笔记 > 100 篇摘抄

### ✅ 要做的事

1. **先记 100 条笔记再说**。100 条之后再回头优化结构
2. **自己的话写**。照搬原文 = 无效笔记，用自己的理解写才有价值
3. **链接优先**。写完笔记花 30 秒想想：这和哪篇有关？打两个 `[[]]`
4. **定期回顾**。知识不用 = 没学。每周翻开旧笔记看一遍

## 常见问题

**Q: 笔记该放 Inbox 还是直接分类？**

快速想法/来不及整理的 → Inbox。明确知道归属的 → 直接放到目标目录。

**Q: 什么时候创建 MOC？**

当一个主题下有 3 篇以上相关笔记时，创建 MOC 把它们串起来。

**Q: 知识卡片和永久笔记的区别？**

知识卡片（02-Areas）：完整的主题笔记，可以很长，有上下文。
永久笔记（05-Zettelkasten/Permanent）：提炼后的原子化观点，一个笔记只讲一件事。

**Q: 要不要用日期做文件名？**

不要。用描述性标题，如 `STAR追问技巧的四个层次.md`，不用 `2026-06-08-笔记.md`。
